# 软组织力学测量交互指南 · Soft-Tissue Mechanics Interactive Guide

同济大学医学博士研究生课程「现代药剂学」文献精读汇报的配套材料：汇报 PPT（PDF）、原文献，以及一个可交互的网页演示，用来把综述中的力学测量方法讲清楚。

## 精读文献
Muñoz Villaescusa C, van der Ven D, Quetzeri-Santiago MA, Fernandez Rivas D. A strategic guide of techniques for biomedical and tissue engineering applications to measure mechanical properties of soft matter, eye and skin. *Advanced Drug Delivery Reviews* 2026;231:115792. DOI: [10.1016/j.addr.2026.115792](https://doi.org/10.1016/j.addr.2026.115792)

## 网页演示内容（8 章）
1. 黏弹性：标准线性固体（SLS）与幂律模型（Bonfanti 等 2020）
2. 分层压痕：Gao 1992 层状基底修正
3. 弹性毛细：Style 等 2013
4. 空化流变：P_c = 5E/6 + 2γ/r（Zimberlin 2007；Pavlovsky 2014）
5. 导波 / 光学相干弹性成像（OCE）：Kirchhoff 板、眼压张力与流体加载（Vella 2012；Ramier 2019）
6. 气流冲击（Corvis ST）：壳刚度估计（Vella 式 3.6），设备参数取自 OCULUS 公开资料
7. 射流穿刺：Tate 模型（Shergold 2006）
8. 布里渊显微：模量换算（Wu 2018；Seiler 2018）

另含按原文表 2/表 3 整理的技术选择器。每个公式和参数都在页面中标注出处，可追溯、可解释。

## English summary
Companion materials for a graduate "Modern Pharmaceutics" journal-club presentation on Muñoz Villaescusa et al., *Adv Drug Deliv Rev* 2026;231:115792 (doi:10.1016/j.addr.2026.115792, CC BY 4.0). Includes the slides (PDF), the open-access paper with attribution, and a single-file interactive web demo covering eight measurement models: SLS/power-law viscoelasticity, Gao layered indentation, elastocapillarity, cavitation rheology, guided-wave OCE, air-puff (Corvis ST), jet penetration, and Brillouin microscopy, each with traceable sources. Animations are qualitative; this is an educational tool, not a clinical one. Licenses: code MIT, slides CC BY 4.0, paper CC BY 4.0 (original authors).
